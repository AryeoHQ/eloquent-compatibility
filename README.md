# eloquent-compatibility
Serve a previous Eloquent model as a PostgreSQL view over its current models' tables

## Installation
```bash
composer require aryeo/eloquent-compatibility
```

The package supports PostgreSQL 14, 16 and 18, on Laravel 12 and 13.

## Documentation
The [package documentation](https://standards-83a7dd.zggitlab.gitlab-dedicated.site/packages/eloquent-compatibility/) covers declaring a compatibility map, installing its schema, and writing through either model.
